# Crypto_Tracker

This is a simple cryptocurrency converter application designed to help you easily track and convert between different cryptocurrencies.

### Features:

- Real-time data: Fetches the latest cryptocurrency prices from a reliable API.
- Multiple currency support: Supports a wide range of popular cryptocurrencies.
- User-friendly interface: Provides an intuitive and easy-to-use interface.
- Conversion calculations: Allows you to quickly convert between any two supported cryptocurrencies.

### Getting Started:

1. Clone the repository:

   git clone https://github.com/[your-username]/Crypto_Tracker.git

2. Install dependencies:

   cd Crypto_Tracker
   pip install -r requirements.txt

4. Run the application:

   python app.py
